# 🏥 AI Disease Predictor

A Machine Learning based web application that predicts possible diseases based on selected symptoms.

Built using **Python, Scikit-Learn, and Streamlit**.
**🚀 LIVE Demo:** [Try!](https://disease-prediction-ai-degx3tq3dozvjbzhbwgoa3.streamlit.app/)

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://disease-prediction-ai-degx3tq3dozvjbzhbwgoa3.streamlit.app/)


## 🚀 Features

* Predicts **41 different diseases**
* User-friendly **Streamlit interface**
* Symptom selection via dropdown
* Machine learning model (**Random Forest**)
* Real-time disease prediction


## 🛠️ Technologies Used

* Python
* Scikit-learn
* Pandas
* NumPy
* Streamlit
* joblib


## ▶️ Run Locally

1.Install dependencies:
pip install -r requirements.txt

2.Run the application:
streamlit run app.py

Then open the link shown in the terminal.


## 📊 Machine Learning Model

* Algorithm: **Random Forest Classifier**
* Dataset: Symptom-based disease dataset
* Total Diseases: **41**
